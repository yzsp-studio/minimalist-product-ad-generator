## 🇨🇳 中文

面向电商卖家、小品牌主理人、独立创作者和个人卖家，把一张产品图做成干净、有节奏、产品质感突出的极简高级广告短片。正式制作前先做一次轻量启动问询，确认时长、比例和风格等必需信息，但不问音乐，因为默认由视频模型同步生成画面与原生音乐。之后依次完成素材检查与产品事实摘要、制作简报确认、产品叙事脊柱选择、导演动效语言、苹果风英文文案、三张独立产品锚定照片、精确节拍文字分镜表，最后生成视频并做交付验证。为保证画面干净，默认不使用四宫格锚定图，因为视频模型可能把宫格版式带进最终画面。独立配乐与音轨替换只在用户明确授权后才执行。

### ✨ 能做什么

- 上传一张商品图 → 先做素材检查与产品事实摘要，再确认制作简报
- 选定产品叙事脊柱并规划动效语言 → 决定广告结构与卡点切换节奏
- 生成苹果风英文广告文案 → 短、干净、卖点前置
- 产出三张独立产品锚定照片 → 锁定产品视觉，避免宫格版式入画
- 默认原生音乐随画面同步生成 → 需要时才走独立配乐替换分支
- 交付前做验证并检查成片 → 目标是无需二次返工

## 🇬🇧 English

Built for e-commerce sellers, small-brand founders, independent creators and solo sellers who want one product photo turned into a clean, rhythmic, premium minimalist ad short. Production opens with a light kickoff questionnaire covering duration, aspect ratio and style — but not music, since the video model generates picture and native audio together by default. The pipeline then runs material checks and a product-fact summary, brief confirmation, narrative spine selection, motion-language direction, Apple-style English copy, three independent product anchor photos, a beat-accurate text storyboard, then video generation and delivery verification. To keep frames clean it deliberately avoids four-panel anchor grids, which the video model can leak into the final picture. Separate scoring and track replacement run only with explicit user authorization.

### ✨ What it does

- Upload one product image → material check and product-fact summary, then brief confirmation
- Picks a product narrative spine and directs motion language → ad structure with beat-synced cuts
- Writes Apple-style English ad copy → short, clean, benefit-first
- Generates three independent product anchor photos → locks product look and keeps grid layout out of frame
- Native music generated alongside picture by default → separate scoring only on request
- Runs delivery verification → checks the film needs no second pass
